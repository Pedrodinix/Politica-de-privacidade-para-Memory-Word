Política de Privacidade do Memory Word

Atualizada em 31 de outubro de 2026.

1. Dados armazenados no dispositivo

O Memory Word é um aplicativo de estudo e memorização. Listas de palavras, conceitos, questões, imagens associadas, configurações e progresso ficam no armazenamento privado do aplicativo no dispositivo. O app não exige criação de conta nem contém anúncios. A base de estudo não é enviada automaticamente a um servidor. Exportar ou compartilhar um backup depende de uma ação do utilizador.

2. Processamento por serviços externos

Quando o utilizador escolhe usar uma função de IA, o texto do conceito, da pergunta ou da resposta, ou a imagem escolhida no scanner, é enviado por HTTPS ao backend do Memory Word na Cloudflare. O backend encaminha a solicitação à API Google Gemini para gerar explicações, avaliar respostas ou extrair questões de imagens. A Cloudflare processa metadados de conexão, incluindo o IP utilizado para limitar solicitações. O código do Worker não registra textos, imagens nem respostas em logs da aplicação.

O projeto usa o nível gratuito da Gemini API. Pelos termos desse serviço, o Google pode usar entradas e respostas para melhorar e desenvolver seus produtos e tecnologias de machine learning; revisores humanos podem ler e processar esse conteúdo. Não envie dados pessoais, confidenciais ou sensíveis nessas funções. As respostas da IA podem conter erros e devem ser revisadas pelo utilizador. A disponibilidade depende da conexão e das cotas do serviço.

A IA não é oferecida no Espaço Econômico Europeu, Reino Unido e Suíça. O servidor usa o país estimado pela Cloudflare a partir do endereço IP para aplicar essa restrição; não solicita localização por GPS. Se o país não puder ser identificado, o acesso à IA é recusado. Os recursos locais continuam disponíveis.

Ao solicitar uma tradução automática, o texto digitado é enviado por HTTPS ao serviço Google Translate para obter a tradução.

Quando o reconhecimento de fala é ativado, o áudio é processado pelo serviço de reconhecimento do sistema. Conforme o dispositivo e o serviço configurado, esse processamento pode usar a nuvem do fornecedor. O Memory Word não envia esse áudio ao backend Gemini.

3. Permissões

A câmera é usada quando o utilizador escolhe fotografar um item de estudo ou uma questão. O microfone é usado no ditado por voz e no treino de pronúncia. As notificações e o reagendamento após reinício servem aos lembretes locais configurados pelo utilizador. As permissões podem ser geridas nas configurações do Android.

4. Armazenamento e exclusão

Os dados locais permanecem no dispositivo até serem apagados no aplicativo, pela limpeza do armazenamento do app ou pela desinstalação. Backups exportados e arquivos compartilhados ficam sob o controle do utilizador e não são apagados automaticamente ao desinstalar. Apagar os dados locais não exclui automaticamente informações já processadas pelos serviços externos. O tratamento e a retenção desses serviços seguem suas próprias políticas; o Memory Word não promete um prazo de retenção que não controla.
